Nearly every pair of requirements is unrelated, so a plain random sample would hold almost no duplicates. Pairs are drawn from each group on purpose, and each group is then weighted by the number of pairs it stands for, so the recall is for all the pairs, not only the ones that were picked. Every fifth pair goes to a second person, which is how agreement between people is measured.
